# Character artwork integration

All ten original PNGs from Abijeason's character-art-cel-shaded.zip are used for
team selection, both rosters and battle fighters. Images are copied unchanged,
with contain sizing and native transparency. Existing opponent mirroring and
movement/effect animations still apply; these are static designs, not animation
frames. Combat definitions and character identities are unchanged.

Source: https://github.com/Zain-ux-lab/Clashbound/issues/20
Package: https://github.com/user-attachments/files/33037542/character-art-cel-shaded.zip
Assets, source notes and exact generation prompts: frontend/assets/characters/.
Arena artwork is separate and is not part of this character-only integration.
