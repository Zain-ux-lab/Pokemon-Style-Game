# Bold cel-shaded character roster

Updated: 4 October 2026

All ten characters recreated using the selected style 5, Bold cel-shaded action.

Hushwing is a collective of five ghostly spirit bats depicted together as one character asset.

## Review

Extract the ZIP and open index.html in a browser. Use the background buttons to inspect the PNG transparency. Each card links to its full image and individual PNG download.

These are static artwork concepts. They have not been integrated into the game and do not include animation frames. The previous artwork is preserved separately.

## Files

Ten named PNGs, index.html, this README, and prompts.json. PNGs retain their native aspect ratios and alpha channels. Use contain sizing when previewing. Scale and animation pivots will need to be chosen during integration.

## Creation

Built-in image generation tool. Each earlier character image supplied identity and anatomy; the selected Mage sample supplied the art direction. Exact prompts and source paths are saved in prompts.json. Colors, costume details and equipment are visual interpretations rather than new canonical lore.
