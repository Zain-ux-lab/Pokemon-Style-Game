# Security Policy

## Supported Versions

This project is in pre-release development and has no stable releases yet.
We will consider reports affecting the current development version.

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do not report them in a
public issue or pull request.

Use [GitHub's private vulnerability reporting](https://github.com/Zain-ux-lab/Pokemon-Style-Game/security/advisories/new)
if it is enabled. Otherwise, contact [zainmalik8b@gmail.com](mailto:zainmalik8b@gmail.com)

Please include:
- A description of the issue and its potential impact
- The affected branch, commit, or version
- Steps to reproduce it, with a minimal proof of concept if possible

Please do not access or modify other users' data, disrupt services, or publicly
disclose the issue before coordinating with the maintainers.

## Response

We aim to acknowledge reports within 7 calendar days and will share updates
as we investigate. The maintainers will coordinate any public disclosure
with the reporter.
